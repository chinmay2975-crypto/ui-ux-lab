Summary-
Orbit is a mobile app concept for Gen-Z users, combining spirituality, meditation, focus and self-growth in a single experience.
Designed as a UI/UX case study, it uses a cosmic, dark visual theme and a five-tab structure: Home, Goals, Meditate, Explore and Profile. 
The project brings together user personas, journey maps, high-fidelity screens and a Nielsen heuristic evaluation, supported by a sample landing-page website used to apply and assess the usability heuristics. Orbit was also compared against the Sadhguru App as a competitor benchmark, examining how an established spirituality app handles navigation, content discovery and user engagement, and using those observations to shape Orbit’s design for a younger audience. Across the assignments,
the design process was unified around a single product, showing how user research and competitor analysis translate into interface decisions.
